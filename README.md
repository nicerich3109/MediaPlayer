# MediaPlayer

Настольный офлайн-медиаплеер для локальной медиатеки.

## Возможности

- Воспроизведение аудио и видео через VLC; для видео воспроизводится аудиодорожка.
- MP3, OGG, WAV, FLAC, M4A, AAC, OPUS, WMA, AIFF и распространённые видеоформаты, поддерживаемые установленным VLC.
- Перемотка, громкость, повтор трека/списка, перемешивание.
- Ручное добавление файлов и синхронизация выбранных папок по запросу.
- Исключение папок из сканирования.
- Плейлисты JSON с путями к исходным файлам без копирования музыки.
- Три варианта интерфейса: Яндекс Музыка, Spotify и SoundCloud; переключение без потери функций плеера.
- Левая панель навигации с разделами «Обзор», «Медиатека», «Плейлисты», «Эквалайзер», «Редактор тегов» и «Настройки».
- Постоянная боковая панель текущего трека с управлением воспроизведением, перемоткой и громкостью.
- Настройки цветов и UI-пресеты в config/ui.json; пользовательские пресеты можно сохранять из приложения.
- Эквалайзер с пресетами «Речь», «Бас», «Спокойный» и ручной настройкой.
- Чтение и редактирование основных аудиотегов; добавление обложки для MP3.

## Установка

Требуется Python 3.10+ и установленный VLC Media Player. Разрядность VLC должна совпадать с разрядностью Python.

```bash
python -m pip install -r requirements.txt
python main.py
```

На Windows установите VLC с официального сайта VideoLAN. На Linux установите системные пакеты VLC и libVLC.

## Данные

- config/settings.json — настройки и каталоги сканирования.
- config/ui.json — цветовые схемы, активный вариант оформления и UI-пресеты.
- data/playlists/*.json — плейлисты с путями к оригинальным файлам.

Автоматического сканирования при запуске нет. Для обновления медиатеки нажмите «Синхронизировать».

## Текущий статус

Это начальная версия приложения. Редактирование обложек реализовано для MP3; запись тегов в видео и поддержка обложек в остальных контейнерах пока не гарантируются. Визуальные темы являются самостоятельной реализацией по мотивам общих принципов интерфейсов музыкальных сервисов; они не подключают онлайн-каталоги или аккаунты этих сервисов. Для воспроизведения и эквалайзера нужна установленная библиотека VLC/libVLC.
